# VeriFact 📰

Fake News Detection using Machine Learning and Natural Language Processing

## Overview

VeriFact is an NLP-driven fake news detection system designed to analyze textual news content and identify misinformation using supervised machine learning techniques. The project focuses on transforming unstructured textual data into numerical representations through feature engineering and classification pipelines.

The system performs credibility analysis on news articles using TF-IDF vectorization, text preprocessing, and multiple machine learning classifiers to distinguish between reliable and misleading content with 89% prediction accuracy.

---

## Features

* Fake news classification using NLP and supervised learning
* TF-IDF based feature extraction for high-dimensional textual data
* Credibility analysis pipeline for misinformation detection
* Real-time text processing and prediction workflow
* Comparative evaluation of multiple machine learning classifiers
